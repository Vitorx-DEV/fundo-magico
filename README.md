# Fundo Mágico

Projeto web desenvolvido com HTML, CSS e JavaScript que permite ao usuário descrever um background desejado e gerar um efeito visual dinâmico.

# Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript

# Objetivo do projeto
Praticar desenvolvimento front-end, manipulação de formulários e organização de código.

## Como executar o projeto
1. Clone o repositório
2. Abra o arquivo index.html no navegador
